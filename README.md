## 🚀 Products I lead

- **HPX** — management and performance hub (tickets, Meta Ads, dashboards, automated reports). Node.js + Express + TypeScript strict on Supabase; React 19 + Vite + Tailwind + shadcn/ui; ~1,200 tests (Vitest + Playwright), Sentry, Docker, continuous deploy on Railway via GitHub Actions; data consolidated in BigQuery.
- **HarmonizaChat** — multi-tenant WhatsApp CRM. Fastify 5 + Prisma + PostgreSQL, realtime via Socket.IO/SSE, AI assistant with RAG and LLM fallback, per-clinic isolation and RBAC.
- **HarmonizaClub** — members area with 200+ active users. Next.js 15 + React 19 + Tailwind v4 + Supabase SSR + Stripe subscriptions.
- **HarmonizaForm** — conversational forms that replaced Typeform: conditional logic, scoring, payments, queued webhooks and e-mail. Fastify 5 + Drizzle + React, RLS per organization.
- **WhatsApp Group Bot** — reads clinic groups with AI, opens and chases pending tasks, sends reports and pushes demands to HPX. Express 5 + BullMQ/Redis + Postgres.
- **Meta Conversions API** — server-side events and Event Match Quality diagnostics on top of the data warehouse; automations in n8n and Nekt.
- **100+ n8n automations** connecting Typeform, Pipedrive, ClickUp, Meta and AI.
